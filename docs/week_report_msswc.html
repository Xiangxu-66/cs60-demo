MS-SWC Loss — 新 Loss 函数介绍

CS60-1 FiveK 色彩美学增强  |  本周新增实验 loss  |  2026-04-22
一句话总结：把图像转到 CIELAB 色彩空间、建多尺度金字塔，用切片 Wasserstein 距离对齐预测图和目标图的色彩分布 —— 让模型学的不只是"每个像素的值"，而是"整体色调的感觉"。

1. 我们解决什么问题

项目本质是色彩美学增强（Color Retouching）：把相机 raw 图变成专家 C 调过的美学风格图。当前训练 loss 是：

L_total = 0.6 · L1  +  0.2 · (1 − SSIM)  +  0.01 · VGG_Perceptual

三个 loss 各有所管：L1 盯每个像素的值，SSIM 盯局部结构，VGG perceptual 盯 ImageNet 特征空间的语义。但 没有一个直接建模"色彩分布"这件事 —— 而 retouching 的核心恰恰是色调、白平衡、饱和度这些全局色彩统计量。

2. MS-SWC 核心思想

MS-SWC = Multiscale Sliced-Wasserstein Contrastive，基于 ECCV 2024 的 MS-SWD。三步走：

① 色彩空间
RGB → CIELAB
感知均匀空间
→
② 多尺度
Gaussian 金字塔
5 个尺度
→
③ 分布对齐
Sliced Wasserstein
128 随机投影

① 为什么用 CIELAB 空间

sRGB 是显示空间，欧氏距离 ≠ 人眼色差。CIELAB 是 1976 年 CIE 为"感知均匀"设计的色彩空间：L 代表亮度（0–100），a 代表红绿轴，b 代表蓝黄轴。在 LAB 里算距离 ≈ 人眼感受到的色差。所以把像素转到 LAB 再比较，比在 RGB 里算 L1 更贴近任务目标。

② 为什么要多尺度金字塔

单一尺度只能看到像素级色差。多尺度（下采样 + 高斯模糊）后，每一层代表不同空间粒度的色彩统计：高层看整体色调，底层看局部色彩细节。5 个尺度求平均 = 同时约束全局和局部色彩。

③ 为什么用 Sliced Wasserstein 距离

把每个尺度的图像看成"一袋 LAB 色彩向量"（忽略空间位置），SWD 衡量两袋分布之间的最优传输成本 —— 直观讲就是"把源分布的色彩'搬运'成目标分布要花多少代价"。

直接算高维 Wasserstein 很贵（传统方法 O(N³)）。Sliced 版本的巧思：

  1. 在 LAB 的 3 维单位球上随机采 128 个方向 θ
  2. 把每袋色彩向量沿 θ 投影成 1D 标量
  3. 1D 情况下，W1 距离 = 排序后对应位置做 L1 差
  4. 128 个方向求平均，作为最终 SWD 值

复杂度降到 O(K · N log N)，完全可微，可直接反传梯度。

3. 算法公式

给定预测图 ŷ、目标图 y，分别转 LAB 并构建金字塔后，单尺度的 SWD 定义为：

SWD(P, Q)  =  (1/K) · Σk=1..K   W1( sort(θkTP), sort(θkTQ) )
           其中   θk ∼ Uniform(S2),   K = 128

多尺度上再取平均得到最终 loss：

LMS-SWC(ŷ, y)  =  (1/S) · Σs=1..S   SWD( Pyrs(LAB(ŷ)),   Pyrs(LAB(y)) ),    S = 5

4. 为什么我们认为它管用

贴任务本质

  • 任务是色调重塑 → LAB 空间直接建模
  • retouching 的关键是全局色彩统计 → 分布距离天然对齐
  • SWD 对"颜色应该出现多少"敏感，不纠结"在具体哪个位置"

弥补现有 loss 空白

  • L1 / SSIM 只管像素位置，不管色域统计
  • VGG perceptual 是 ImageNet 语义特征，和颜色关系弱
  • MS-SWC 直接填上"色彩分布"这个维度
它有个天然局限 —— 也正是我们的切入点
因为 SWD 忽略空间位置，单独用会损失像素级精度（预计 PSNR 下降 1–3 dB）。所以它不会替代 L1/SSIM，而是作为第三维补充。最终 stage 配方会是 L1 + SSIM + MS-SWC 三维互补。

命名 "MS-SWC" 是我们起的 —— 把 MS-SWD 的多尺度切片 Wasserstein，与对比（Contrastive）结构组合。本周先实现前半（positive-only），对比项留作下一步。

6. 实现情况

主文件 src/losses/ms_swc_loss.py，约 120 行纯 PyTorch：

  • 可微 sRGB → CIELAB 转换（D65 白点，标准矩阵）
  • 可学习可关闭的 Gaussian 金字塔（sigma=1.0，kernel=5）
  • SWD 核心：每次 forward 重采 128 个单位球方向、投影、排序、L1
  • 默认超参与 ECCV 2024 论文对齐（5 scales × 128 projections）

已写 6 个单元测试全绿：恒等（loss(x, x) = 0）、梯度非零有限、色调偏离远 > 小扰动、权重线性缩放等。代码已推到 origin/Zijian。
